**Owner, 2026-11-07:** "kötta o fixa allt i ordning". That approves the design below. Under E141 the three open choices are decided as the recommendations, and they are recorded here so the next session does not re-ask them.

## Decisions already made

| | Decision |
|---|---|
| (a) | A pre-fill writes a **DRAFT** to `config/manual/drafts/<T>.<origin>.yaml`, never straight into the live store. `vss manual --merge-draft --ticker T` merges it after a backup. It never overwrites an existing figure: a conflict is printed side by side and left. **Why:** SPEC §5b says the ranking key is not gated on status, and `prepare` runs the filter limbs on `manual.as_record`, so a live UNVERIFIED figure would leak into both. |
| (b) | **New ruling E149**, written into FRAMEWORK-EDITS and placed in `tools/playbook/placement.py` in the same commit: E131's `machine_read_back` may NOT verify a figure whose origin is `esef-ixbrl` or `llm-pdf`. Quotecheck proves the transcription. It cannot prove the choice of line, and choosing the line is what the machine did. Only the owner flips these figures to VERIFIED. Quotecheck output is shown to him as an audit aid. |
| (c) | ESEF figures land **UNVERIFIED** (unlike `sec-xbrl`, which lands VERIFIED/tagged). Revisit only after about three names have been audited with zero defects. |

Hard rules that stay in force:
- Fail closed.
- DATA MISSING rather than a guess.
- No silent scaling or derivation.
- Every pre-filled figure is UNVERIFIED and carries its page or tag.
- A zero is never machine-emitted, because the E25 `zero_basis` is a human claim.
- No judgement fields are machine-filled: `interest_source`, lease classification, `not_presented`, `bound`.

## The order. Commit after each step and run the full suite.

### A1. The provenance gap (do this FIRST)

`tools/fetch_mfn.py` (built 2026-11-07) writes NO `sources/manifest.json` entry, so its roughly 340 PDFs are "PROVENANCE NOT RECORDED" (SPEC §5a).
- Write an entry for each download using the same record shape as `vss/nordic.py` `_record_for`: URL, SHA-256, bytes, release time, declared vs actual content type, `downloaded_at`, and `source: mfn`.
- Back-fill entries for the files already on disk, marked `recorded_after_the_fact`, built from the MFN feed item and the bytes on disk.
- Accept ESEF packages as well, detected by the bytes (`PK` plus `META-INF/taxonomyPackage.xml`), not by name. MFN serves them as `.xbri` or `.zip` with content type `application/octet-stream` or `application/zip`. EVO, ACAD and OLVI have them; Zinzino has none, because First North is an MTF and ESEF does not apply.
- Tests go in `tests/test_fetch_mfn.py`.
- Then port to `~/vss-public` and run `deploy` (the timer `vss-mfn` runs this nightly).

### A2. `vss/esef.py`, the ESEF reader

- Open the package and find `reports/*.xhtml`.
- Reuse `vss/ixbrl.py` `facts_from_inline`. It already reads `ifrs-full`, skips dimensional contexts, and applies scale, sign and dash-as-zero. Instead of an accession, use the package SHA-256 plus the filename; the filing date is the manifest release date.
- **The LEI in the contexts must equal the LEI in `config/mfn_entities.yaml`, or fail closed.**
- Currency comes from `unitRef`. Record `decimals`.
- Issuer extension concepts (for example `PAN:`) are NEVER mapped. Report them as "extension, not read".
- Real-data facts from Pandora's 2025 package:
  - 363 numeric facts, 323 of them `ifrs-full`, 0 dimensional.
  - **Tagged:** Revenue, ProfitLossFromOperatingActivities, CashFlowsFromUsedInOperatingActivities, PurchaseOfPropertyPlantAndEquipmentClassifiedAsInvestingActivities, PurchaseOfIntangibleAssetsClassifiedAsInvestingActivities, PaymentsOfLeaseLiabilitiesClassifiedAsFinancingActivities, Short- and LongtermBorrowings, FinanceCosts, Assets.
  - **Not tagged:** lease-liability balances, interest paid and share counts. Notes are tagged as text blocks only.
- Fixtures: a **synthetic** minimal package of about ten facts. It must cover `scale=6`, `sign=-`, fixed-zero, one dimensional fact (skipped), one extension concept (not read), an LEI-mismatch case and a comparative-year context. Commit no real issuer documents.

### B. LLM pre-fill from PDF pages (First North names, interims, note figures; first name ZZ-B.ST)

1. New `source.pdf_pages()` returning `[(pdf_index, printed_label, text)]`. **`pdf_to_text` and its tests stay untouched.**
2. A deterministic page locator that scores pages by statement headings in en, sv, fi, da and no ("Consolidated statement of cash flows", "Kassaflödesanalys", "Rahoituslaskelma", ...). Only the top pages go to the model.
3. Schema: a subset of `manual.FieldSpec`, statement lines only. Per field the model returns the value, the verbatim row, the verbatim column header, the verbatim unit sentence and the PDF page. Run twice using the `extract.agreement()` pattern; a disagreement drops the field.
4. Gates. Each failure drops the field to DATA MISSING:
   - **The quote is on that page:** `quotecheck.find_quote` returns EXACT or NEAR, and `value_in` finds the value in the quote.
   - **Column header:** it contains the target period's year or date.
   - **Scale:** applied ONLY when the unit sentence is quoted from the same page.
   - **Unit:** `config.unit_problem` on op_income / revenue vs op_margin.
   - **One scale:** `_check_one_scale` across the drafted periods.
   - **No zeros, and no judgement fields.**
5. Origin `llm-pdf`. A sidecar run record holds the model id and hashes of both runs. The same draft and merge flow applies.
- Fixtures: page-text fixtures plus canned responses through `extract`'s `transport` injection. Cover a disagreement, a wrong column, an unquoted unit, a missing quote and a zero.
