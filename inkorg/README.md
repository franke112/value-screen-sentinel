notes, spreadsheets. No need to rename or sort anything.

where it belongs (the table in `../CLAUDE.md`, "Inkorg -> where it goes"),
and asks instead of guessing when it is unclear. The folder is empty when
Claude is done. Nothing is deleted -- what has no home goes to `../arkiv/`.
