One term, one translation, everywhere -- chapters, diagrams, index, sources.
Plain, modern Swedish; the register of a good popular-science book, not a
bank prospectus. Write "du" to the reader, never "ni".

## Never translate
- Code, file names, paths, module and function names, command lines
  (`vss run`, `config/watchlist.yaml`, `rules.py`).
- Ruling numbers (E28, B41, F1), section numbers (§4.2, 5.1C).
- URLs, HTML attributes, class names, ids, CSS, anchors (`#n3`).
- Book and paper titles in source lists (keep the original title; translate
  only the descriptive words around it).
- Proper names (Buffett, Graham, Rappaport, SEC EDGAR, Yahoo, Claude).
- Numbers and units: keep the figures, use Swedish decimal comma only in
  running prose (12,5 %), never inside code or diagram coordinates.
